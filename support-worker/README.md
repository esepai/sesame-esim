# Чат поддержки «Сезам eSIM» — сервер ИИ-ассистента

Виджет чата (`support.js`) уже стоит на сайте. Пока сервер не подключён, он работает в **демо-режиме** с заготовленными ответами. Эта папка — маленький сервер на Cloudflare Workers, который:

- хранит ключи API в секрете (в браузер они не попадают);
- отвечает клиентам через **Claude** (Anthropic) или **OpenAI** — переключается одной настройкой;
- знает тарифы, страны, совместимость телефонов, установку, оплату и возвраты — база знаний собирается из `index.html`;
- передаёт диалог **сотруднику в Telegram**, когда клиент просит человека, есть вопрос по заказу или возврату или ответа нет в базе.

Ассистент честно представляется ИИ-ассистентом и не выдаёт себя за человека.

## Запуск (≈15 минут)

Нужен Node.js 20+ и бесплатный аккаунт Cloudflare.

```bash
cd support-worker
npm install
npx wrangler login
```

### 1. Ключ ИИ

- **Claude:** создайте ключ на console.anthropic.com → API Keys, затем `npx wrangler secret put ANTHROPIC_API_KEY`.
- **OpenAI:** создайте ключ на platform.openai.com, затем `npx wrangler secret put OPENAI_API_KEY`. В `wrangler.toml` поставьте `AI_PROVIDER = "openai"` и впишите в `OPENAI_MODEL` модель из вашего аккаунта.

### 2. Telegram для сотрудников

1. В Telegram напишите @BotFather → `/newbot` → получите токен бота.
2. Добавьте бота в чат поддержки (или напишите ему сами) и узнайте `chat_id` — например, через @userinfobot или `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Сохраните секреты:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
```

### 3. Публикация

```bash
npm run deploy
```

Команда пересоберёт базу знаний из `index.html` и выдаст адрес вида `https://sezam-support.<аккаунт>.workers.dev`.

### 4. Подключение к сайту

В `index.html` и `partners.html` впишите адрес с `/chat` на конце:

```js
window.SEZAM_SUPPORT={endpoint:'https://sezam-support.<аккаунт>.workers.dev/chat',page:'main'};
```

Если сайт переедет на свой домен, добавьте его в `ALLOWED_ORIGINS` в `wrangler.toml` и выполните `npm run deploy`.

## Обновление знаний

После любого изменения цен, стран или вопросов на сайте выполните `npm run deploy` — база знаний пересоберётся автоматически. Посмотреть её можно в `src/knowledge.ts`. Поведение ассистента (тон, правила передачи сотруднику) настраивается в `src/prompt.ts`.

## Локальная проверка

```bash
cp .dev.vars.example .dev.vars   # впишите ключи
npm run dev                      # сервер на http://localhost:8787/chat
```

На время проверки поставьте на сайте `endpoint:'http://localhost:8787/chat'`.

## Расходы и защита

- **Расходы.** Ассистент работает на `claude-opus-5-5` с низкими затратами на «размышления» — ответы быстрые и короткие. Неизменная часть инструкций кэшируется, поэтому повторные запросы дешевле. Расходы видны в консоли Anthropic или OpenAI. Рекомендуем поставить там месячный лимит.
- **Ограничения.** Не больше 20 сообщений в минуту с одного IP, 30 последних сообщений в истории, 2000 символов в сообщении. Запросы принимаются только с сайтов из `ALLOWED_ORIGINS`.
- **Чего ассистент не видит.** У него нет доступа к заказам и платежам. Такие вопросы он передаёт сотруднику, предварительно попросив у клиента контакт.
